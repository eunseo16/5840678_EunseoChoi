# Quicksort { Result Image }
![](./14-quicksort.jpg)

선택 정렬은 시간 복잡도가 평균, 최선, 최악 모두 n²으로 높은 시간 복잡도를 가진다.
삽입 정렬은 시간 복잡도가 최선은 n, 평균과 최악은 n²이다.
버블 정렬은 시간 복잡도가 최선은 n^3/2, 평균과 최선은은 n²이다.
쉘 정렬은 시간 복잡도가 평균은 n^3/2, 최선과 최악이 n²이다.
합병 정렬은 시간 복잡도가 평균, 최악, 최선 모두 n log n이다.
퀵 정렬은 시간 복잡도가 최악이 n², 평균과 최선이 n log n이다.
퀵 정렬은 시간 복잡도가 평균적으로 n log n이기 때문에 데이터의 크기가 커질수록 선택, 삽입, 버블 정렬과의 성능 차이가 크게 벌어진다. 퀵 정렬과 합병 정렬은 유사한 성능을 보이지만 메모리 효율성에서 퀵 정렬이 유리하다. 퀵 정렬은 대규모 데이터에서 압도적으로 빠르다.
